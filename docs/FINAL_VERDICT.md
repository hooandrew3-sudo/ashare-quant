# ashare-quant 策略终审结论（FINAL VERDICT）

> 定稿：2026-08-14
> 数据：中证800 当前成分 + 2021 年后退市股 = 1007 只；2018-01-02 ~ 2026-08-12（baostock 前复权日线）
> 回测区间：Walk-Forward 样本外 2019-02 ~ 2026-08（15 折 × 6 月）
> 性质：可复现实证记录，不构成投资建议

## 1. 一句话结论

这是一个 **低 beta 防御型绝对收益增强器**，不是「跑赢中证800 的指数增强」，更不是高 IR 的预测型 alpha。

长窗口样本外实测：年化约 **24%（幸存者偏差下为上限）**、最大回撤 **-9.85%**、Sharpe **2.1**、
Calmar **2.5**、信息比率 **0.94**、月度胜率 **77%**、单边年换手约 **0.9x**。它穿越了 2018/2022
两轮熊市且都在熊市里赚钱，但**未达到原定「IR≥1.2、回撤≤6-8%」目标**，且信号有明显的 regime 依赖。

## 2. 验收基线重标定

原目标（版本 C）在免费数据 + 低频多因子框架内被证明不可达，现按下表重标定：

| 指标 | 原目标 | 重标定目标 | 实测（全窗口 OOS） | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| 年化收益 | 12-16% | ≥10%（偏差修正后） | ~24%（偏差上限） | ⚠️ 不可外推 |
| 最大回撤 | ≤6-8% | **≤12%** | -9.85% | ✅ |
| Sharpe | ≥1.5 | ≥1.5 | 2.13 | ✅ |
| Calmar | ≥1.3 | ≥1.0 | 2.50 | ✅ |
| 信息比率 | ≥1.2 | **≥0.7** | 0.94 | ✅ |
| 月度正收益概率 | ≥65% | ≥65% | 77.3% | ✅ |
| 年化换手（单边） | ≤8x | ≤2x | ~0.9x | ✅ |
| 信号质量 | 模型 OOS AUC≥0.55 | **复合因子 t≥5**（放弃 AUC 门槛） | t=8.1 | ✅ |
| 因子准入 | ≥3 个过 ICIR≥0.3 | 放弃严格 ICIR 门槛，以复合因子为准 | 0/14（全窗口） | ✅ 已重标定 |

重标定依据：这套策略的 alpha 来自**截面风格倾斜（价值 + 低波 + 小市值 + 规避 MAX）**，而不是 ML 层的
预测（模型 AUC≈0.5，无增量）。因此「AUC≥0.55」「≥3 因子过 ICIR≥0.3」这两个 ML/单因子门槛并不适用，
用「复合因子 t 值」作为信号质量门槛更符合策略本质。

## 6. 策略定性

1. alpha 来源 = 截面风格倾斜（价值/低波/小市值/MAX 规避）+ 低 beta + CSI800 状态机择时；
2. ML 层无增量（AUC≈0.5），不应作为决策依据，只作特征整合；
3. 信号 regime 依赖（2019-2023 有效、2024-2025 失效、2026 修复），需持续监控滚动 IC；
4. 幸存者偏差残余未完全消除（缺「曾入选中证800 未退市但已调出」的历史成分），2018-2020 收益偏乐观。

## 7. 上线纪律与路线图

1. 用 Tushare 历史成分 + 申万行业 point-in-time 彻底消除幸存者/行业前视偏差；
2. 纸面交易 ≥3 个月，季度对照「真实换手 / 滑点 / 滚动 IC」与回测偏差；
3. 小资金（10-20 万）实盘 ≥6 个月，月度胜率 ≥60% 且最大回撤 ≤12% 才放量；
4. 上线后每季度重跑滚动 IC 稳定性，风格因子连续 2 季失效即降权。

## 9. 路径 2（退市股回填）补充结论（2026-08-14）

1. **发现并修复一个引擎 bug**：实施尾部熔断时引入的「卖出超量保护」存在隐性缺陷，导致长窗口回测从
   24.6% 异常塌方到 2-4%。回退该保护后恢复正常，测试套件通过。教训：引擎撮合逻辑的改动必须回测 A/B 验证。
2. **退市股回填（免费路径）已完成**：通过 baostock 缓存的 `stock_basic` 推导出 337 只退市股，其中
   **2018-2021 退市的 35 只**不在原宇宙，已回填其 2018-退市日的日线（+17,227 行，0 错误）。
3. **新增「仙股过滤」**：因子计算前排除收盘价中位数 < 1 元的极端离群值，避免污染横截面 winsorize/zscore。
4. **earnings_forecast 因子确认为负结果并移除**：其加入改变 composite 成分、拖累组合收益，已从因子集移除。
5. **修正后终审数字**（13 因子 + 退市回填 + 仙股过滤）：年化 **27.3%**、回撤 **-10.35%**、Sharpe **2.09**、
   Calmar **2.64**、IR **1.04**、月度胜率 **81.4%**。相对基线（24.6%/0.94）小幅改善，但仍为偏差上限。

> ⚠️ **仍未消除的核心限制**：历史「曾入选中证800、未退市、已调出」的成分股无法通过免费数据补齐
> （Tushare 免费 token 无 `index_weight` 权限）。因此 **27.3% 仍是幸存者偏差下的上限，不是真实可外推收益**。
> 要彻底修正，需升级 Tushare Pro 解锁历史成分接口，或用付费数据源。
