## 三、⚠ 必须声明的对比局限(如实记录,不作"证伪/证实")

**OLD run 与 NEW run 不可直接对等比较**,因为它们不是"同配置 PIT 修复前后"的对照:

| 维度 | OLD (20260818) | NEW (20260819) |
|---|---|---|
| config_fingerprint | `2a069d34d5ac` | `f75f83d6d7c1` |
| strategy_fingerprint | `797ba5f8960f` | `6651b9cbc504` |
| data_fingerprint | `11382888643500642310` | `8586454136753724792` |
| horizons(周期×种子) | 12 个(5/10/20/40 日×3 种子) | 1 个(20 日×1 种子) |
| n_estimators | 250 | 300 |
| n_folds | 60 | 5 |
| 回测区间覆盖 | 601 交易日 | 259 交易日 |

**两个断言:**
1. **数据指纹不同**(`1138…` vs `8586…`):`data/processed/prices` 的 parquet bundle 两次之间发生过变化,`bundle.prices` 的 hash 不同。鉴于数据源是 baostock 且曾有增量同步(daily.log 里 8-18 崩溃前后),**prices 极可能被增量覆盖或部分补数过**,但本次未取证数据指纹差异的具体来源。
2. **配置指纹不同**(current default.yaml 的 `n_estimators=300`、`horizons=[20]`、`n_seeds=1`;OLD run 用的是更早的多周期多种子配置)。

因此 NEW 与 OLD 之间"超额 −2.22% vs −49.83%""Sharpe 0.91 vs −0.50"的差异,**主因是配置与数据包差异,不足以归因于任何策略/代码改进**。

## 四、对"ML 无增量"结论的再评估(修正后的立场)

综合 NEW run 新证据,结合 FINAL_VERDICT 的历史证据:

1. **ML 层无增量这一核心结论,在 NEW run 上仍未被推翻**:
   - 新 OOS AUC=0.5055 与旧 AUC=0.5007 均紧贴 0.5,同源结论:LightGBM 对"20 日跑赢基准"几乎没有判别信息。
   - ML 层的 IC(0.021)即便有微弱正值,其幅度与噪声(仅 5 折)不足以支撑"ML 提供 alpha 增量"的论断。
   - 两个不同配置/不同数据包的独立跑,ML AUC 都 ≈0.5 → **这一结论具备跨配置稳健性**,可信度上升。

2. **但组合层表现为"风格暴露/防御型"这一点,NEW run 发生了量级变化**:
   - 超额从 −49.83% 收窄到 −2.22%,Sharpe 转正(0.91),beta 仍低(0.315)。
   - 这更可能反映 **数据窗口与配置不同**(259 天采样区间不同、单周期单种子),**而非策略本质改善**。
   - **必须明确**:本轮并**未**修复 P0-3(industry PIT 滚动 / fundamental 缺失显式建模),因此残留 PIT 对 ML-alpha 真假的影响**仍未闭合**,无法用于一锤定音。

## 五、结论与建议(不被本次主观乐观读数带偏)

- **本次重跑不构成对"ML 层无增量"结论的证伪或证实**,因为非有效对照(配置与数据指纹都不同)。
- **新证据的增量价值**: 在另一个独立配置/数据组合下,ML AUC 再次 ≈0.50,为"ML 层无增量"结论提供了**跨配置稳健性背书**。
- **要真正一锤定音,仍需做一次有效对照**:
  1. 固定一个明确数据包(冻结一副 prices/fundamentals/industry 快照,记录 data_fingerprint);
  2. 仅改 P0-3(industry PIT 滚动 + fundamental `is_missing` 哑变量);
  3. 用**同一套** default.yaml 跑两次(修复前后),对比 OOS AUC / RankIC / 超额 / IR;
  4. 若修复后 ML 层 IC/IR 仍无显著提升 → 正式确认"ML 层无增量"并落地为生产定论;若提升 → 说明旧结论被 PIT 残留污染,需重写。
