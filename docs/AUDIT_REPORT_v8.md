## 四、遗留问题清单（需专项重构，本轮仅记录）

按优先级排序，均为审计确认的真实缺陷：

1. **复权架构断裂（数据层最大缺陷，P0 级）** — 增量同步用前复权价（adjustflag="2"），每次除权后整条历史序列重新缩放，但增量合并只替换重叠窗口 → 接缝两侧比例尺不同，产生虚假跳空污染净值/因子/止损。`adj_factor` 列现为常量 1.0 占位。
   **方案**：落库改存不复权 OHLC + preclose，用本地复权因子按需计算前复权；过渡期靠新增的单日跳变告警（C6）监控。涉及 backfill 全量重跑。
2. **幸存者偏差（结构性）** — csi800 成分取当前快照做历史回测；baostock 有 `query_hs300_stocks(date)` 按日期快照接口未被使用。年化收益高估可达数个百分点。
3. **基准为价格指数** — 中证800 价格指数不含股息，组合隐含享受红利再投 → 超额收益/IR 年化虚高约 2~2.5pp。应换全收益指数 H00906 或对基准加估算股息率。
4. **行业映射静态外推** — 用今天的行业分类回填全历史（compute.py/selection.py/risk_budget.py 均取 keep="last"），应改为按调仓日 merge_asof(as_of_date)。
5. **低价股过滤用全样本中位数**（compute.py:25-28）— 宇宙构建层面的轻度前视，应逐日 expanding。
6. **财务 as-restated ≠ as-reported** — akshare 业绩报表返回今日重述值贴历史公告日，温和前视，报告中声明即可。
7. **QMT 实盘冒烟验证** — 契约已修正但未经真实 xtquant 运行验证。接入资金前必须完成模拟账户全流程测试 + OMS 账本启用确认。
8. **多周期集成评估标签错配**（train.py ensemble 用 h_max 标签评混合周期分数）→ drift 监控指标失真。
9. **性能二阶项**：compute.py 逐 symbol merge_asof 循环可全局向量化（预计 10x）；synthetic 生成双层 Python 循环；risk_budget 协方差全套计算只用对角线（建议删除）。
10. **暴露调节四层相乘**（regime × beta × signal_health × smallcap）无法归因，建议合并为单一 ExposureGovernor。

| Sharpe（各自口径） | -0.213（几何式） | 0.363（标准式） | 0.363 | 0.389 |
| 信息比率 IR | -1.111 | -0.972 | -0.841 | -1.001 |
| 超额收益（累计） | -45.9% | -42.9% | -35.5% | -41.8% |
| 基准收益 | +47.1%（价格指数） | +54.5%（含息修正） | +47.1% | +54.5% |
| 月度胜率 | 40.0% | 56.7% | 56.7% | 53.3% |
| 年化换手 | 1.23x | 1.14x | 1.14x | 1.22x |

### 8.1 结论分解

1. **t 值水分量化**：同一样本上 naive 全样本 t=17.45 → NW 校正后 4.87 → 再限定 OOS 区间后 **0.97**。旧口径的"高度显著"约 95% 来自方法论偏差（自相关膨胀 + 准入窗口泄漏），而非真实 alpha。
2. **股息修正的贡献（B0 vs B1）**：组合完全相同（年化/回撤/换手逐项一致），仅基准曲线不同——累计超额差 7.46pp ≈ **每年 2.6pp 的超额虚高被消除**，与审计预测的 2~2.5pp 吻合。此为纯"报表诚实度"修复，不改变任何交易。
3. **止损冷却的贡献（B0 vs B2）**：关闭冷却年化 +0.42pp、但回撤恶化 0.82pp、月胜率 -3.4pp、换手 +0.08x、费用 +7%。63 日冷却在季度调仓频率下偏长，存在"错过复牌反弹"的机会成本 → **优化方向：冷却期网格 21/42/63 日对比，或改为'冷却期内降权 50% 复购'替代一刀切禁买**。
4. **整体效应（A vs B0）**：+4.0pp 年化、+16.7pp 月胜率、-0.09x 换手。注意这同时包含代码修复效应与 purge 后重训模型的随机性差异，不应外推为"修复能提升收益"；核心收益是**数字可信度的量级修正**。

### 8.2 剩余问题定位（优化优先级）

所有变体 IR 均深度为负（-0.84 ~ -1.11）：**当前最大矛盾不在工程层，而在策略层**——防御型低 beta 风格在 2024-2025 含息基准大涨 47%~55% 的窗口内结构性跑输。工程修复已完成使命（把失真从数字中剔除），后续优化应聚焦：

1. **风格自适应**：regime 已识别牛市档位，但组合仍满仓低 beta 名单 → 研究按 regime 切换因子权重（牛市提高动量/盈利质量权重）而非只调仓位；
2. **门禁阈值再校准**：新口径下合理阈值区间为 1.5~2.5（对应 NW-OOS 有效样本），达到后再恢复硬拦截；
3. **止损冷却参数网格**（21/42/63 × 季度/月度调仓交叉）；
4. 遗留 §7.5 的数据层两项重构不变。

## 十、与优秀量化策略的差距分析 + 信号层实验（2026-08-26）

### 10.1 差距画像（基于全部实证证据）

### 10.3 实验二：regime 条件化复合权重轮动

机制：牛市/熊市分域估计成分与权重（估计窗口 ≤ cutoff，无前视），逐日按基准 MA120 状态选用；分域样本不足自动回退全窗口权重。2×2 矩阵（牛市子窗 2024-02~2026-07）：

| :-- | :-- | :-- |

| 轮动 ON | **G2: 13.64% / -6.73% / 胜率66.7%** | H2: 10.60% / -8.91% |

- 轮动在两种特征规则下均占优（年化 +1.2/+1.7pp，回撤更浅）；补满特征反而稀释（弱特征拖累 LightGBM），保留最小补齐规则；
- **但全窗口稳健性检验否定采纳**（2022-01~2026-07, n_splits=8）：G2 参数 4.44%/-9.63%/IR+0.036 vs E8 参数 5.46%/-9.45%/IR+0.108 —— 牛市窗改进是 regime 特有，非稳健 alpha；

### 10.4 门禁阈值重校准（任务②收口）

全部近期运行的 OOS+NW composite_t 分布：**[0.63, 1.00]**（E8/G1/G2/H2）。决策：
- `gate_min_composite_t` 5.0 → **1.5**（新口径下的晋级目标线）；维持告警模式——当前 t≈1 未达标，达标且跨窗口稳定后才恢复硬拦截；
- 生产模型已按当前代码重训注册（`20260826_083417_caf881258ed4`，12.40%/-8.61%，与 G1 逐位一致验证可复现性），live 链路验证通过。

### 10.5 结论：差距的本质与路径

本轮实验的价值在于**排除了两条看似合理的捷径**（盈利质量因子、regime 轮动均无稳健增量），把矛盾聚焦到唯一根本项：**截面信号强度不足（t≈1）**。在该项改善之前，组合层/参数层打磨的边际收益低于噪声。优先级重排：
1. **数据基建先行**：现金流报表接入 → 真正的盈利质量因子族；point-in-time 成分消除幸存者偏差（当前所有数字仍系统性偏乐观）；
2. 信号广度：数据许可下把有效因子从 3~5 扩到 15+（分析师覆盖变化、股东户数、北向等低相关源），靠广度提升复合 t（主动管理基本定律 IR≈IC·√B）；
3. 门禁 1.5 达标后恢复硬拦截，再谈放大资金。
