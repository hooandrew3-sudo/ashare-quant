## 一、执行摘要

本审计发现 **1 个 P0 数据污染事故**（已修复）、**3 个 P1 级缺陷**、**4 个 P2 级问题**，并基于 **1053 只真实 A 股数据**完成 equal vs risk_budget 组合方法 A/B 回测对比。

**核心结论：**
1. 系统架构整体扎实（Walk-Forward 严格时序、T+1/涨跌停/停牌处理正确、无因子未来函数）
2. 但存在**数据层致命缺陷**：synthetic 演示数据可覆盖真实数据，且复权因子恒为 1.0
3. 真实数据回测显示：risk_budget 将最大回撤从 -6.68% 降至 -3.86%（-42%），代价是收益减半
4. 模型信号偏弱（OOS AUC≈0.51），因子层强信号（composite IC=0.04, t=17）未完全传导到模型

## 三、P1 级发现（严重，需限期修复）

### 3.1 复权因子恒为 1.0（数据层）

**位置**：`quant/data/baostock_sync.py:272`
```python
prices["adj_factor"] = 1.0  # 从未填充真实复权因子
```

**风险**：
- 当前 prices 用 `adjustflag="2"`（前复权）拉取，回测/因子计算直接用复权价，**当前结果不受影响**
- 但**增量同步有隐患**：前复权价会随分红/拆股重算历史，导致每次同步历史价格漂移 → 训练数据不可复现、数据指纹变化
- 一旦未来需要"原始价+复权因子"模式（如生成除权缺口标记），adj_factor=1.0 会静默失效

**工业级修复**：
- 拉取时改为 `adjustflag="1"`（后复权）或同时存 `adj_factor` 真实值
- 或改用"原始价 + 复权因子"存储，回测时动态复权

### 3.2 概率校准在 OOS 全量上 in-sample 拟合（模型层）

**位置**：`quant/pipeline.py` 校准块
```python
calib.fit(oos_flat["score"], oos_flat["y_true"])  # 用全部 OOS 拟合
oos = calib.transform(oos_flat["score"])           # 再变换同一份 OOS
```

**风险**：用同一份 OOS 数据既拟合又变换，校准器"看到"了答案，导致校准后的概率偏乐观（overfit）。

**工业级修复**：改为 K-fold 内校准（Out-of-Fold calibration）：
- 将 OOS 按 fold 拆分，用其他 fold 拟合校准器，变换当前 fold
- 或保留 20% 的 holdout 校准集

**影响评估**：对排序/选股影响小（单调变换），但对概率绝对校准有偏差。实盘使用概率阈值（如 score>0.7 才建仓）时需修复。

### 3.3 行业分类为静态快照（数据层）

**位置**：`quant/data/baostock_sync.py:171-179` + `restore_industry.py`

**问题**：industry 用的是 2026-08-10 的**当前快照**，回测 2018-2022 时也用现在的行业分类。历史行业归属变化（如公司转型）未反映。

**风险**：行业中性化在历史上可能错误归因。对月频多因子影响中等（证监会行业分类较稳定）。

**工业级修复**：接入历史行业分类（Tushare 积分接口），或对行业中性化因子做敏感性分析。

## 五、真实 A 股 A/B 回测对比（300 只股票，2018-2026 数据，OOS 2025-12~2026-07）

### 5.1 核心指标对比

| 指标 | baseline_equal | risk_budget | 差异 |
|------|---------------|-------------|------|
| 总收益 | +72.2% | +35.3% | -51% |
| 年化收益 | 117.2% | 53.9% | -54% |
| **Sharpe** | **5.86** | **3.88** | -34% |
| **最大回撤** | -6.68% | **-3.86%** | **+42% 改善** |
| Calmar | 17.5 | 14.0 | -20% |
| IR | 3.75 | 2.32 | -38% |
| Beta | 0.370 | **0.234** | 降 37% |
| 年化换手 | 6.30 | **5.68** | 降 10% |
| 成本拖累 | 4,091 元 | **3,212 元** | 降 21% |
| 卖出命中率 | 35.0% | 34.6% | ≈持平 |

### 5.2 关键解读

1. **组合方法选择是"收益-风险"权衡**：
   - risk_budget 用风险预算把高波动股票的权重压低 → 回撤减半、Beta 大降
   - 代价是放弃了部分高波动高收益暴露 → 收益减半
   - 卖出命中率持平（35%）说明**两种方法的选股质量一样**，差异完全来自权重分配

2. **模型信号偏弱**：
   - OOS AUC=0.5056（≈随机）、OOS Rank IC=0.0106、ICIR=0.416
   - 但**因子层信号强**：composite IC=0.0405、t=17.46；动量 t=8.98；小市值 t=10.31
   - 说明模型集成（多因子 → LightGBM → 概率）丢失了部分因子信息，模型有待改进

3. **⚠️ 回测区间过短**：
   - 仅 8 个月（8 个调仓日），年化收益严重失真（117%/54% 无实盘意义）
   - 需要拉长回测区间（2-3 年）验证统计显著性
